The GITO, GITOC and the Information Regulator ask whether the department's security and privacy posture is sufficient to carry citizen trust. The Cyber Security Maturity Assessment is drawn from the security gates already scored across the estate — assessed against PSR Regulations 94–95, POPIA and the interoperability security requirements. It is not a separate audit; it is the security dimensions of the same assessment, gathered into one view.

The exposure is at the exchange, not the perimeter. The weakest dimension by far is data exchange secured, logged and monitored (1.29): data moves by scheduled dump and removable media, unencrypted and unlogged. That is simultaneously the cyber risk and the POPIA breach — the same defect the Conformance Dashboard records under data protection. Closing it is the security case for the integration fabric (W1), which replaces every manual exchange with a governed, logged API.
